# 烧录与真机验收

确认开发板为微雪ESP32-S3-Touch-AMOLED-1.75C，连接支持数据传输的USB线，在已激活ESP-IDF的终端构建：

```sh
./scripts/build.sh --build-dir /tmp/chameleon-pet-build
./scripts/flash.sh --list-ports
./scripts/flash.sh --port /dev/cu.usbmodem你的设备
```

Windows在ESP-IDF终端进入`dist`后执行：

```sh
python -m esptool --chip esp32s3 --port COM你的设备 --baud 460800 write-flash @flash_args
```

复刷前核对`SHA256SUMS`、设备型号和分区表，并自行备份重要存档。脚本使用`flash_args`选择bootloader、分区表、应用，不执行`erase-flash`，现有相同分区布局下保留NVS；不同来源固件的布局不能默认兼容。不要直接用完整`merged.bin`覆盖已有用户数据。

首次启动使用新幼年宠物；同版本体系复刷保留原宠物、森林材料、闹钟和音量。完成后在实际开发板上检查显示、按钮点击、抚摸、捕食张嘴伸舌、游戏、短按侧键息屏及唤醒。校时后检查闹钟、昼夜天气和森林日历；音量、供电与耗电需要实际测量。

本仓库没有任何个人开发板的MAC、序列号、备份、Wi-Fi密码或串口日志。
