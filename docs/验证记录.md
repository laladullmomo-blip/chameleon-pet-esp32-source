# 公开源码验证范围

发布版本为0.4.7，提供幼年／少年／成年完整软件及素材，不携带原开发历史或私人设备数据。

| 项目 | 软件验证范围 |
| --- | --- |
| 原养成规则 | 82组，包括成长、照顾、疾病、计时、亲密度及纪念 |
| 森林规则 | 16组，包括愿望、采集、制作、日历、奖励去重及上限 |
| 小游戏 | 11组，包括捕虫、叶子换位、记忆动作及拖球 |
| 每日闹钟 | 19组，包括现实时间、静音、延后及去重 |
| 音频 | 音量范围、静音、铃声余量及原互动声音 |
| 原生LVGL界面 | 83组，包括圆屏布局、真实指针事件、三阶段五场景、存档迁移和坏记录保留 |

公开版本另行检查所有文件和提交元数据，确认不含本机用户名、家庭目录、开发板标识、个人邮箱、Wi-Fi配置或原Git历史；图片资产无GPS／设备／作者EXIF。上游作者的公开版权声明按许可证保留，GitHub发布账号作为仓库所有者仍可见。

本版在独立源码目录进行ESP32-S3构建和SHA校验；构建状态与源码提交记录于本机生成的`dist/build-info.json`。构建输出、设备存档及日志不提交到仓库。软件检查不代表用户自己的开发板已经烧录或通过实际触控、声音、供电和续航验收。
